## Project 1: Numerical Simulation of a Series RLC Circuit
**Course:** Technical Computing Software (HDD4060)  
**Tools:** MATLAB, Simulink, Simscape Electrical

### Overview
This project investigates the dynamic behaviour of a series RLC circuit through mathematical analysis and numerical simulation. It focuses on resonance, current response, damping, and the phase relationship between current and voltage.

### My Contributions
- Built the Simulink model of the series RLC circuit.
- Analysed the mathematical theory behind the circuit's behaviour.
- Conducted simulation tests under different conditions.
- Interpreted simulation results and compared them with theoretical predictions.

### What I Learned
This project helped me understand how mathematical models can be used to analyse electrical systems. I learned the importance of testing models under different conditions, interpreting simulation results, and comparing numerical results with theoretical expectations.
